# Nguyễn Huy Kiên — Portfolio CV

Website CV/portfolio cá nhân giới thiệu Nguyễn Huy Kiên, kỹ năng, dự án và thông tin liên hệ. Giao diện sử dụng phong cách neon cyberpunk và được thiết kế responsive cho điện thoại, máy tính bảng và máy tính để bàn.

## Nội dung trang

- **Giới thiệu:** thông tin cá nhân và các nút điều hướng đến dự án, liên hệ.
- **Kỹ năng:** HTML, CSS, JavaScript, responsive design, Git/GitHub và Figma.
- **Dự án:** các thẻ dự án minh họa.
- **Liên hệ:** email, GitHub, Facebook, Discord và biểu mẫu liên hệ.

> **Lưu ý:** Các liên kết “Xem chi tiết” của dự án hiện chưa trỏ đến trang dự án cụ thể. Biểu mẫu liên hệ đang dùng giá trị mẫu `YOUR_FORM_ID`; cần thay bằng mã Formspree hợp lệ để gửi tin nhắn thật. Khi chưa cấu hình, trang chỉ hiển thị thông báo gửi thử.

## Công nghệ

- HTML5
- CSS3: Flexbox, CSS Grid, custom properties và media queries
- JavaScript thuần cho xử lý biểu mẫu liên hệ
- Formspree dự kiến dùng làm dịch vụ nhận tin nhắn

Dự án không dùng framework, không cần package manager và không có bước build.
